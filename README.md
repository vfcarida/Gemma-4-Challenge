## 📖 Executive Vision

GemmaBridge is an offline-first, multimodal AI assistant engineered to democratize inclusive education. It bridges the critical communication gap for neurodiverse students—specifically those on the autism spectrum—within public education systems.

By 2026, the enrollment of students with Autism Spectrum Disorder (ASD) in basic education has surged. However, true inclusion is blocked by a severe "Inclusion Gap": an overwhelming deficit of specialized educators, rigid physical communication tools, and a chronic lack of reliable internet in marginalized areas. Traditional augmentative communication, like physically printed PECS (Picture Exchange Communication System) cards, requires hours of manual preparation and fundamentally restricts children from expressing immediate, complex needs.

GemmaBridge dismantles these barriers by acting as a real-time, context-aware companion for educators. Leveraging the local-first processing power of Gemma 4 E2B, it guarantees enterprise-grade performance, absolute data privacy for minors, and total independence from internet connectivity.

## ✨ Key Features

*   **Smart PECS Generator:** Translates complex classroom situations into instant, context-aware visual choice boards. Supports multiple scenario categories (food, emotions, transitions, math, social, self-regulation).
*   **Open Board Format (OBF) Integration:** Export created visual boards as standard-compliant `.obf` files or import OBF JSON configurations generated by external AAC tools.
*   **Accessible Student Mode & Sensory Settings:** A full-screen, touch-friendly, and cognitively accessible interface. Teachers can configure:
    *   **Sensory-Friendly Mode Toggle:** Mutes bouncy transition animations and simplifies visual highlights to prevent sensory overload.
    *   **Speech Speed & Pitch Modulators:** Customizes TTS speed rate and audio pitch overrides to suit students with sound sensitivity.
*   **Dynamic Lesson Adaptor:** Analyzes standard lesson plans across core subjects and suggests prioritized, autism-friendly adaptations.
*   **Student Profiles:** Manage student profiles with granular sensory preferences and behavioral notes.
*   **Offline-First & Privacy-Focused:** Runs entirely locally via the storage abstraction layer. Data is persisted securely in the browser—nothing leaves the device.

## 🚀 Getting Started

### Prerequisites
Ensure you have the following installed on your local machine:
*   **Node.js**: `v18.17.0` or higher
*   **npm**: `v9.0.0` or higher

### Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/vfcarida/GemmaBridge.git
   cd GemmaBridge
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Access the application:**
   Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🧠 How it uses Gemma 4

In GemmaBridge, we leverage the efficiency and reasoning capabilities of the **Gemma 4 E2B** model to power a local-first assistive technology for inclusive classrooms:

1.  **Local-First Privacy:** By utilizing the highly optimized E2B (Edge-to-Browser) variant, GemmaBridge bypasses the need for internet access. This ensures that sensitive minor data never leaves the device.
2.  **Context-Aware Reasoning:** The application simulates deep, context-aware reasoning when analyzing a student's behavioral triggers.
3.  **Hardware Efficiency:** Designed for edge computing on standard school laptops (4-6GB RAM), we leverage Per-Layer Embeddings (PLE) to keep active parameters exceptionally low.
